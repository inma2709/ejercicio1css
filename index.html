1. Qué es CSS

CSS es el lenguaje que usamos para decidir el aspecto de una página HTML: colores, letras, tamaños y espacios.

Para aplicar CSS a nuestra página HTML, conectamos el archivo styles.css desde el head del documento.

Una regla CSS

Selector: indica qué elemento queremos modificar.

Propiedad: indica qué característica queremos cambiar.

Valor: indica cómo queremos que quede.

🎨 Antes de empezar: colores y estilos de nuestra página

Nuestra paleta de colores

Para no repetir los mismos colores continuamente, vamos a guardar nuestra paleta en variables CSS.

Las declararemos en :root para poder utilizarlas después en toda la página.

  • Fondo: #e8edf1
  • Principal: #30343F
  • Secundario: #1A1B41
  • Acento: #C62E65
  • Blanco: #FFFFFF
  • Suave: #F0E9FF
  • Destacado: #FFF0B8
  • Aviso: #E3F2FD

Podemos declararlas así:

:root {
    --color-fondo: #e8edf1;
    --color-principal: #30343F;
    --color-secundario: #1A1B41;
    --color-acento: #C62E65;
    --color-blanco: #FFFFFF;
    --color-suave: #F0E9FF;
    --color-destacado: #FFF0B8;
    --color-aviso: #E3F2FD;
}

Degradado para el header

Para el fondo del encabezado vamos a utilizar un degradado formado por tres colores. 

background: linear-gradient(
    135deg,
    #c27898 0%,
    #9da4d6 50%,
    #94bbe9 100%
);

135deg indica la dirección del degradado y los porcentajes indican en qué punto aparece cada color.

¿Por qué los enlaces aparecen azules?

Los navegadores aplican algunos estilos por defecto a los enlaces, como el color azul y el subrayado. Si queremos sustituirlos por nuestros propios estilos, podemos usar color: inherit; para que el enlace herede el color de su elemento padre y text-decoration: none; para eliminar el subrayado. 

a {
    color: inherit;
    text-decoration: none;
}

color: inherit; hace que el enlace herede el color de su elemento padre.

text-decoration: none; elimina el subrayado que añade el navegador.

Los enlaces del menú son anclas internas. El valor que escribimos después de # debe coincidir con el id del elemento al que queremos desplazarnos.

Por ejemplo, el enlace que utiliza href="#cajas" nos lleva hasta el elemento que tiene id="cajas".

2. Cómo seleccionamos elementos

Antes de escribir CSS debemos pensar qué elemento queremos modificar y después elegir el selector adecuado.

  • Selector de etiqueta: modifica todos los elementos de ese tipo.
  • Selector de clase: permite aplicar un mismo estilo a varios elementos.
  • Selector de ID: permite identificar un elemento concreto de la página.

Este párrafo tiene una clase llamada destacado. Le hemos puesto un borde sólo a la izquierda. La misma clase podría utilizarse en otros elementos de la página.

La cascada determina qué regla termina aplicándose cuando varias reglas afectan al mismo elemento.

Algunas propiedades, como el color o el tipo de letra, pueden heredarse de un elemento padre.

Soy un parrafo con la clase recordatorio. Aparezco con un estilo diferente para llamar la atención del usuario.

4. Tamaño de los elementos

La propiedad width permite establecer el ancho de un elemento.

Si utilizamos un valor fijo muy grande, como 900px, la caja puede desbordarse en pantallas más pequeñas.

Por eso muchas veces utilizamos un ancho relativo, como un porcentaje, junto con max-width.

max-width establece el ancho máximo que puede alcanzar una caja. De esta forma puede adaptarse a espacios más pequeños sin superar el límite indicado.

min-width establece el ancho mínimo que puede tener un elemento.

Debemos utilizar min-width con cuidado, porque impedir que una caja se haga más pequeña también puede provocar desbordamiento en pantallas estrechas.

Una altura fija puede producir problemas cuando el contenido necesita más espacio. Antes de utilizar height, piensa si el contenido puede cambiar o crecer.

5. El modelo de caja

Todo elemento HTML genera una caja.

El contenido se encuentra en el interior. Alrededor podemos encontrar padding, border y margin.

Esta es una caja real: el fondo llega hasta el padding, el borde marca su límite y el margin la separa de los elementos que tiene alrededor. Prueba primero a cambiar solo su padding y después solo su margin.

Padding: espacio dentro de la caja

El padding crea espacio entre el contenido y el borde de una caja.

Prueba a aumentar el padding. ¿Qué ocurre con la distancia entre el texto y el borde?

Margin: espacio fuera de la caja

El margin crea espacio alrededor de una caja.

No separa el contenido de su borde: separa la caja de los elementos que tiene alrededor.

Los cuatro lados de una caja

Podemos cambiar cada lado con propiedades como margin-top o padding-left. Con cuatro valores, el orden es arriba, derecha, abajo e izquierda. Con dos valores, el primero se aplica arriba y abajo, y el segundo a los lados. Prueba: padding: 1rem 3rem;.

¿Qué hace margin: auto?

El valor auto permite que el navegador calcule automáticamente el margen disponible.

Si una caja tiene un ancho menor que el espacio disponible, el navegador puede repartir el espacio sobrante a izquierda y derecha.

Esto permite centrar horizontalmente determinadas cajas.

Cambia el ancho de esta caja y observa qué ocurre.

Con box-sizing: border-box, el ancho indicado para una caja incluye su contenido, el padding y el borde.

Esto significa que al calcular el ancho de una caja, no necesitamos sumar el padding y el borde, ya que están incluidos en el ancho total.

Comprueba la diferencia

Las dos cajas de este ejemplo tienen exactamente las mismas medidas: width: 32rem, padding: 2rem y borde: 8px. La única propiedad que cambia es box-sizing. La caja exterior usa content-box. La caja interior usa border-box.

content-box

El width solo mide el contenido. El padding y el borde se suman al ancho visible.

border-box

Esta caja está dentro de la anterior. Tiene el mismo width, padding y borde, pero aquí el width ya incluye el padding y el borde.

6. Cuando el contenido no cabe

Una caja puede tener menos altura que el contenido que guarda. La propiedad overflow permite decidir qué ocurre con ese contenido.

7. Imágenes

Una imagen también ocupa una caja y podemos controlar su tamaño desde CSS. Le estamos dando una sombra para que tenga profundidad.

Prueba a modificar: el ancho, el ancho máximo, el borde y el redondeado de las esquinas.

8. Antes de escribir CSS, piensa

  1. ¿Qué elemento quiero modificar?
  2. ¿Cómo voy a seleccionarlo?
  3. ¿Qué propiedad necesito?
  4. ¿Estoy cambiando su aspecto, su tamaño o el espacio de su caja?

Un elemento interactivo de HTML

HTML también incluye algunos elementos interactivos que funcionan sin necesidad de JavaScript.

La etiqueta details permite crear un bloque de contenido que podemos abrir y cerrar.

La etiqueta summary contiene el texto visible sobre el que hacemos clic para mostrar u ocultar el contenido.

summary debe estar dentro de details y normalmente aparece como su primer elemento.
